Multimodal AI-Based Image Understanding System

A single Flask application that validates an uploaded image, generates a structured image analysis (description, objects, activities, caption, summary, uncertainties), validates the JSON against a fixed schema, and then evaluates the analysis for errors, omissions and unsupported observations.

        5. How this maps to the question, plus test instructions
        
    
        
      
        
        
        
          
         Requirements demonstrated
        
          
        
            
          
              
        • Detailed description, objects + attributes, activities, caption, summary, uncertainties.
          • 
              
        • Offline demonstration mode that never claims to be a live model, and never attaches a sample
                  description to a different image (exact SHA-256 match only).
          • 
              
        • Optional live vision-language provider (Anthropic Claude and Google Gemini) with credentials
                  read from environment variables and complete error handling.
          • 
              
        • Real image validation: contents are decoded with Pillow, corrupted/oversized/empty files are rejected.
          • 
              
        • Separate validator module for JSON syntax + schema, and a separate evaluation module.
          • 
              
        • Manual review controls (confirm / reject / edit / add) and a downloadable report.
          • 
              
        • pytest suite with all external model calls mocked.
          •
